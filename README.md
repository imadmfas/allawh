# اللوح المحاور

منصة مجانية تحوّل كتب المنهج العراقي إلى كتب تفاعلية، من الأول الابتدائي إلى السادس الإعدادي.

**الرابط:** https://imadmfas.github.io/allawh/

إعداد البروفيسور عماد محمد فرحان، باستعمال المساعد الذكي كلاود (Claude).

## طريقة العمل

1. يكتب الطالب اسمه ويختار صورته عند أول دخول.
2. يختار المرحلة: الابتدائية أو المتوسطة أو الإعدادية، ثم الصف، ثم الفرع العلمي أو الأدبي في الإعدادية.
3. تظهر أغلفة كتب الصف، والكتاب الجاهز يُفتح بلمسة.
4. الصفوف من الأول إلى الخامس الابتدائي دروسها ألعاب ومراحل ونجوم. وبقية الصفوف دروس وتجارب واختبار في نهاية كل فصل يفتح الفصل التالي.
5. الصفوف المنتهية (السادس الابتدائي، الثالث المتوسط، السادس الإعدادي) فيها أسئلة على نمط الامتحان الوزاري.

يُحفظ ملف الطالب وتقدّمه على جهازه فقط، ولا تُجمع أي بيانات.

## البناء

البوابة صفحة ثابتة بلا خطوة بناء: `index.html` و`app.js` و`data/catalog.js`.
كل كتاب في مستودع مستقل منشور على النطاق نفسه، فتقرأ البوابة نجوم الطالب من تخزين المتصفح المشترك.

- إضافة كتاب جاهز: عدّل حالته في `data/catalog.js` إلى `ready` وضع رابطه.
- الفحص اللغوي: `python3 tools/lint_ar.py`

## الاشتراك

- الدرس الأول من كل فصل في كل كتاب مجاني، وكلمة السر تفتح كتب الصف كله.
- ترتبط كلمة السر بجهاز واحد، وتنتقل إلى جهاز آخر بعد تسجيل الخروج من الأول، أو بفك ارتباطها من صفحة الإدارة.
- الخادم مشروع Supabase، وإعداده كله في `supabase/setup.sql`.
- صفحة الإدارة: https://imadmfas.github.io/allawh/admin.html
- ربط كتاب بالاشتراك:

```js
import { gate } from 'https://imadmfas.github.io/allawh/access.js';
if (await gate({ grade: 's6-sci', lesson: 7 })) openLesson(7);
```
